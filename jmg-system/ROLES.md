# Roles & Accountability

| Role | Owns | Does not do |
|------|------|-------------|
| **Owner / Principal** | Positioning, qualification decisions, final pricing, contracts, key client relationships | Day-to-day site supervision |
| **Admin / Coordinator** | Lead intake, tracker upkeep, scheduling, document filing, invoicing follow-up | Price negotiation |
| **Estimator / Design Lead** | Site measurement, scope write-up, BOQ, design drawings, proposal build | Committing schedule without PM |
| **Project Manager** | Pre-con, schedule, procurement, subcontractors, weekly client update, change orders, closeout | Changing scope without a signed change order |
| **Foreman / Site Lead** | Daily crew direction, quality checks, safety, daily log, photos | Client commercial discussions |
| **Crew / Subcontractors** | Executing to spec and schedule, keeping site clean | Verbal scope changes |

## Escalation path
Foreman → Project Manager (same day) → Owner (within 24h for cost, schedule, or client-relationship issues).

## RACI summary
- **Pricing:** Owner (A/R), Estimator (C), PM (C)
- **Schedule:** PM (A/R), Foreman (C), Owner (I)
- **Quality on site:** Foreman (R), PM (A)
- **Client communication:** PM (R), Owner (A)
- **Change orders:** PM (R), Owner (A), Client (approves)
