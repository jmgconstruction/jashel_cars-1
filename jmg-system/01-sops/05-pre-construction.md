# SOP 05 — Pre-Construction

**Goal:** Eliminate surprises before the first day on site.
**Owner:** Project Manager **Exit gate:** Checklist 100% complete; client kickoff held.

## Checklist
- [ ] Signed contract and deposit on file
- [ ] Permits and approvals secured (or timeline confirmed)
- [ ] Final drawings and specifications issued for construction
- [ ] Material selections confirmed in writing (finishes, fixtures, colors)
- [ ] Long-lead items ordered (confirm delivery dates)
- [ ] Master schedule built with milestones and inspection points
- [ ] Subcontractors confirmed and briefed
- [ ] Budget tracker set up (contract value + cost codes)
- [ ] Site logistics: access, storage, utilities, security, working hours
- [ ] Safety plan and PPE confirmed
- [ ] Neighbors informed (if applicable)
- [ ] Client kickoff meeting held: schedule, communication rhythm, decision deadlines, how change orders work
- [ ] Project folder created (contract, drawings, selections, photos, logs)

## Rule
No mobilization until every box is checked.
