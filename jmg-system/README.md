## The Pipeline (7 stages)

| # | Stage | Owner | Exit gate | SOP |
|---|-------|-------|-----------|-----|
| 1 | Lead intake | Admin / Owner | Lead logged, response sent < 24h | [01](01-sops/01-lead-intake.md) |
| 2 | Qualification | Owner | Client scored ≥ 7/10 or respectfully declined | [02](01-sops/02-client-qualification.md) |
| 3 | Site visit & scope | Estimator / Owner | Written scope + assumptions agreed | [03](01-sops/03-site-visit-scope.md) |
| 4 | Proposal & contract | Owner | Signed contract + deposit received | [04](01-sops/04-proposal-contract.md) |
| 5 | Pre-construction | Project Manager | Pre-con checklist 100% complete | [05](01-sops/05-pre-construction.md) |
| 6 | Build / field execution | PM + Foreman | Weekly reports on time, no open safety items | [06](01-sops/06-field-execution.md) |
| 7 | Closeout & referral | PM / Owner | Punch list cleared, final walkthrough signed, review requested | [07](01-sops/07-closeout.md) |

## Folder map
- `01-sops/` — step-by-step procedures for each stage
- `02-templates/` — proposal, change order, daily log, punch list, weekly update, project tracker (CSV)
- `03-scripts/` — client-facing messages and scripts (pricing frame, qualification, decline, follow-up)
- `OPERATING-RULES.md` — standards that don't bend
- `ROLES.md` — who owns what
- `KPIs.md` — what we measure weekly

## How to use it
1. Every lead gets a row in `02-templates/project-tracker.csv` (or import it into Zoho Projects / Notion).
2. Move the project through the stages only when the **exit gate** is met.
3. Use the templates as-is; improve them in a pull request so the whole team gets the update.
